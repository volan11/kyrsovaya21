# Инструкция пользователя (вариант 21, Санузел)

## 1. Открыть проект в Wokwi
1. Откройте ссылку на проект Wokwi из `README.md` (или создайте новый проект Arduino Uno и вставьте в него `sim/sketch.ino`, `sim/diagram.json` и `sim/libraries.txt`).
2. Нажмите зелёную кнопку Start Simulation.
3. Ползунком датчика MQ2 меняйте уровень дыма, переключателем PIR — присутствие, полем Humidity датчика DHT22 — влажность.
4. При дыме выше 25 % включаются реле и красный светодиод, в Serial Monitor появляется `EVENT … type=THRESHOLD`.

## 2. Получить лог
Выделите весь вывод Serial Monitor, скопируйте и вставьте в файл `data/log.txt` (заменив старое содержимое). Сохраните файл.

## 3. Запустить Node-RED и загрузить данные
1. Дважды щёлкните `env.bat` (командная строка с git, node и sqlite3), затем запустите `start-nodered.bat`.
2. Откройте http://localhost:1880, меню ≡ → Import → выберите `nodered/flow.json`, нажмите Deploy.
3. После сохранения `data/log.txt` данные автоматически попадают в `db/variant.db`. Если этого не произошло, нажмите кнопку у узла «Загрузить лог вручную».

## 4. Посмотреть данные
```
sqlite3 db\variant.db ".read db\queries.sql"
```
Покажет десять последних показаний, минимум/среднее/максимум по датчикам, все события и число записей.

## 5. Проверить неисправность
Скопируйте строку из `data/log_fault.txt` в `data/log.txt`, сохраните и повторите запрос 3: в таблице events появится событие `FAULT` с текстом «датчик s1 вне диапазона».
