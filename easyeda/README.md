# Материалы EasyEDA

Принципиальная схема варианта 21 «Санузел», выполненная в EasyEDA:

- `SCH_milenakyrsovaya_2026-10-29.json` – исходный файл проекта EasyEDA (экспорт EasyEDA Source, импорт: File → Open → EasyEDA Source);
- `schematic.png` – схема (изображение);
- `schematic_and_bom.pdf` – листы с рамкой и основной надписью: схема электрическая принципиальная и перечень элементов;
- `bom.csv` – перечень элементов (BOM).

Обозначения: U1 – Arduino Uno, U2 – MQ2, U3 – PIR, U4 – реле, DHT1 – DHT22, D1 – красный светодиод, D2 – светодиод нагрузки, R1 = 150 Ом, R2 = 220 Ом.
